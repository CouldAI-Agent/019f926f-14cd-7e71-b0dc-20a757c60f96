# Mu

A minimal, Zen-inspired Flutter application that simply displays "無" (Mu), embracing emptiness and simplicity.

## Features
- Ultra-minimalist user interface.
- Automatic light and dark mode support based on system settings.
- Cross-platform support (iOS, Android, Web, Desktop).

## Tech Stack
- Flutter
- Dart

## Setup and Run
1. Ensure you have Flutter installed.
2. Run `flutter pub get` to fetch dependencies.
3. Run `flutter run` to start the app.
